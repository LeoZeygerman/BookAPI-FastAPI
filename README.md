# 📚 BookAPI — REST API для управления библиотекой

**BookAPI** — учебный backend-проект на Python, реализованный с использованием FastAPI, PostgreSQL и асинхронного SQLAlchemy.

Приложение предоставляет REST API для управления книгами, авторами, жанрами и обзорами. Помимо стандартных CRUD-операций, реализованы поиск, работа со связанными сущностями и аналитические SQL-запросы.

Проект создан для практического изучения backend-разработки, асинхронного программирования, проектирования баз данных и построения REST API.

## 🏗️ Архитектура проекта

Проект разделён на несколько логических слоёв:

- **Routers** — HTTP-маршруты и обработка входящих запросов.
- **Services** — бизнес-логика и взаимодействие с базой данных.
- **Models** — ORM-модели таблиц PostgreSQL.
- **Schemas** — Pydantic-модели для валидации запросов и формирования ответов.
- **Database** — создание асинхронного подключения и управление сессиями.
- **Config** — загрузка настроек из переменных окружения.

## 🗄️ Структура базы данных

В проекте реализованы четыре основные сущности:

| Сущность | Описание |
|---|---|
| Books | Информация о книгах |
| Authors | Информация об авторах |
| Genres | Жанры книг |
| Reviews | Обзоры пользователей |

### Связи между таблицами

- **Authors → Books:** один ко многим (One-to-Many).
- **Books ↔ Genres:** многие ко многим (Many-to-Many) через промежуточную таблицу `genre_book`.
- **Books → Reviews:** один ко многим (One-to-Many).

Для загрузки связанных данных используется `selectinload`, позволяющий заранее загружать отношения ORM-моделей.

## 📊 Аналитические SQL-запросы

Помимо CRUD, приложение содержит запросы для получения статистики.

Реализованы:

1. Топ-5 авторов по количеству написанных книг.
2. Авторы с определённым количеством книг.
3. Авторы, количество книг которых выше среднего.
4. Топ-10 книг по количеству обзоров.

В реализации используются:

- `JOIN`
- `GROUP BY`
- `HAVING`
- `COUNT`
- `AVG`
- `ORDER BY`
- Подзапросы
- Агрегатные функции PostgreSQL

Запросы формируются средствами SQLAlchemy.

## 🛠️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/LeoZeygerman/BookAPI-FastAPI.git
cd BookAPI-FastAPI
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация на macOS/Linux:

```bash
source .venv/bin/activate
```

Активация на Windows:

```powershell
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install fastapi "uvicorn[standard]" sqlalchemy asyncpg pydantic pydantic-settings
```

### 4. Настройка PostgreSQL

Создайте базу данных PostgreSQL, например `bookapi`.

В корне проекта создайте файл `.env`:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASS=your_password
DB_NAME=bookapi
```

Замените `your_password` на пароль вашего пользователя PostgreSQL.

Файл `.env` не должен попадать в Git-репозиторий.

### 5. Запуск приложения

```bash
uvicorn app.main:app --reload
```

После запуска API будет доступен по адресу:

```text
http://127.0.0.1:8000
```

При запуске приложение создаёт отсутствующие таблицы базы данных через SQLAlchemy.

## 🔍 Пример запроса

Создание новой книги:

```http
POST /books/
Content-Type: application/json
```

```json
{
  "book_title": "Преступление и наказание",
  "description": "Роман Фёдора Михайловича Достоевского",
  "author": "Фёдор Достоевский",
  "genres": [
    "Роман",
    "Классическая литература"
  ]
}
```

При создании книги приложение проверяет наличие автора и жанров. Если соответствующие записи отсутствуют, они создаются автоматически.
