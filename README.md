# 📚 Book API

Небольшой **начальный проект REST API для управления книгами**, созданный в процессе изучения backend-разработки на Python.

Проект реализован с использованием **FastAPI** и **SQLAlchemy** и работает с базой данных SQLite.

> ⚠️ Это учебный проект начального уровня. Он создан для практики FastAPI, работы с базами данных, SQLAlchemy и построения REST API.

---

## 🛠 Используемые технологии

- 🐍 **Python 3**
- ⚡ **FastAPI**
- 🗄 **SQLite**
- 🔗 **SQLAlchemy**
- 🔄 **Async / await**
- 🚀 **Uvicorn**
- 📦 **Pydantic**

---

## 📌 Возможности

API позволяет выполнять основные CRUD-операции с книгами:

- ➕ Добавить книгу
- 📖 Получить список всех книг
- 🔎 Получить книгу по ID
- ✏️ Изменить информацию о книге
- 🗑️ Удалить книгу

Для каждой книги используются следующие данные:

- `id` — уникальный идентификатор
- `title` — название книги
- `author` — автор
- `release_date` — год выпуска

## 🚀 Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone <ссылка-на-репозиторий>
cd book-api
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
```

### 3. Активировать виртуальное окружение

Для macOS / Linux:

```bash
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Запустить сервер

```bash
uvicorn app.main:app --reload
```

После запуска API будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## 🔗 Основные endpoints

| Метод | Endpoint | Описание |
|------|----------|----------|
| `POST` | `/books/` | Добавить книгу |
| `GET` | `/books/get_all` | Получить все книги |
| `GET` | `/books/{book_id}` | Получить книгу по ID |
| `PATCH` | `/books/{book_id}` | Изменить книгу |
| `DELETE` | `/books/{book_id}` | Удалить книгу |
